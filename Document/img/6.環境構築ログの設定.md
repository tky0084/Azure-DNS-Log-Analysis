
## 仮想ネットワークフローログ(Hub環境)の作成

Hubの仮想ネットワークにて、「監視 | 仮想ネットワーク フロー ログ」 → 「作成」を押下する

![alt text](<スクリーンショット 2026-05-04 215620.png>)

「基本」タブにて、以下の情報を入力する

プロジェクトの詳細

| 項目 | 入力方法 |
|:---------|:---------|
| サブスクリプション | Hubのリソースグループが存在するサブスクリプション |
| フローログのタイプ | 仮想ネットワーク<br>「ターゲット リソースの選択」より、Hubの仮想ネットワークを選択しておく |
| サブスクリプション | 仮想ネットワークと同じリージョン |

インスタンスの詳細

| 項目 | 入力方法 |
|:---------|:---------|
| サブスクリプション | Hubのリソースグループが存在するサブスクリプション |
| ストレージアカウント | 新しいストレージアカウントの作成<br>任意のストレージアカウント名(グローバルで一意の値)と、アカウントの種類をStorageV2(汎用 v2)と入力し、それ以外はデフォルトで作成 |
| リテンション期間(日数) | 0 |

![alt text](<スクリーンショット 2026-05-17 221758.png>)

<br>

「分析」タブにて、以下を入力して作成する

| 項目 | 入力方法 |
|:---------|:---------|
| Traffic Analytics を有効にする | チェックを入れる |
| Traffic Analyticsの処理処理間隔 | 10 分ごと |
| サブスクリプション | 仮想ネットワークと同じリージョン |
| Log Analytics ワークスペース | 作製したLog Analytics ワークスペース |

![alt text](<スクリーンショット 2026-05-04 220737.png>)

<br>

仮想ネットワークフローログは、「NetworkWatcherRG」というリソースグループに自動的に作成されます。

![alt text](<スクリーンショット 2026-05-04 220942.png>)

<br>

## DNSセキュリティポリシーの作成

> 上記の仮想ネットワークフローログでは、インターネットやADに対してどのような通信がどの程度あったかが表示されます。<br>
> しかし、**仮想ネットワークフローログでは、DNS Private Resolverはサポートされていません。**<br>
> 表示されているように見えても、実は正常ではない可能性があるため、仮想ネットワークフローログでDNSのクエリ検索をすることは望ましくありません。<br>
> そこでDNSセキュリティポリシーの診断設定から、DNSクエリについてのログを出力するように設定します。

<br>

### DNSセキュリティポリシーの作成

Azure Portalで「DNSセキュリティポリシー」と検索し、作製を押下する

![alt text](<スクリーンショット 2026-05-06 004345.png>)

<br>

基本タブにて、以下を入力する

| 項目 | 入力方法 |
| -- | -- |
| サブスクリプション | Hubのリソースグループが存在するサブスクリプション |
| リソース グループ | Hubのリソースグループが存在するリソース グループ |
| インスタンス名 | dnssp-hub-prod-prod-network-01  |
| リージョン | Hubの仮想ネットワークと同じリージョン |

![alt text](<スクリーンショット 2026-05-06 004431.png>)

<br>

仮想ネットワーク リンク タブにて、Hubの仮想ネットワークを追加する

![alt text](<スクリーンショット 2026-05-06 004448.png>)

<br>

DNS トラフィック規則タブはそのまま次へ<br>
※特定のドメインに対するアクセスを制限します。

![alt text](<スクリーンショット 2026-05-06 004454.png>)

<br>

「概要」タブにて問題なければ作成する

![alt text](<スクリーンショット 2026-05-06 004509.png>)

<br>

作製したDNSセキュリティポリシーにて、左ペインより「監視 | 診断設定」を押下し、「診断設定を追加する」を押下する

![alt text](<スクリーンショット 2026-05-06 004627.png>)

<br>

診断設定について下記の設定を行い、保存する

| 項目 | 入力方法 |
| -- | -- |
| 診断設定の名前 | 任意の名前 |
| カテゴリグループ | allLogsにチェックを入れる |
| 宛先の種類 | Log Analytics ワークスペースへの送信にチェックを入れる  |
| サブスクリプション | Hubの仮想ネットワークと同じサブスクリプション |
| Log Analytics ワークスペース | Hubに作成したLAWを選択 |

![alt text](<スクリーンショット 2026-05-06 004724.png>)
